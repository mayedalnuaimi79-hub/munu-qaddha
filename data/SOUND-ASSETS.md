# Sound guessing category

24 original synthesized effects generated by `scripts/build-sounds.py`, with a fixed random seed. These are sound-effect approximations, not field recordings. No external audio or song samples. Mono PCM WAV at 24 kHz/16-bit, 6 seconds each. Normalized peak below 0.8, with boundary fades. Files use opaque names fx-01 through fx-24 so their URLs do not give away the answer.

The browser's native audio control requires a user tap and uses preload=none. Navigation/render changes pause the current element. Audio URLs are copied into saved deck snapshots, like map image URLs. Existing no-repeat tracking applies unchanged. All 552 previous main questions and the independent letter bank remain unchanged in this update.
